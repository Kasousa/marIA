# Architecture Decision Records

Uma decisão por arquivo, numerada (`NNNN-titulo.md`), a partir de `0000-template.md`.
Escreva um ADR quando a decisão for difícil de reverter ou quando alguém (humano ou agente) poderia reabrir a discussão.
As decisões já registradas em `docs/spec/` não precisam de ADR; ADRs são para decisões novas ou mudanças na spec.

- [0002](0002-git-flow.md): Git Flow padrão, com release e hotfix validadas em staging
- [0003](0003-regiao-conta-e-entrada.md): us-east-1, conta única e entrada por API Gateway (sem ALB)
